# ランダムコール要件定義に未解決事項の回答を反映

## 何を行ったか

[.kiro/specs/random-call/requirements.md](../.kiro/specs/random-call/requirements.md) の未解決事項5件への回答を反映した。

- ログイン画面 → 一旦ログインなしで実装。ストーリー6を「ログインなしでの利用者の識別」（端末ごとの利用者識別子）に改め、ログイン画面・アカウント紐付けを Non-Goals に移動。ストーリー1の未ログイン時の基準を削除し、Jitsi表示名はアプリから設定しないことにした。セキュリティ・プライバシー・依存関係・制約も合わせて修正。
- 通話ルームの有効時間 → 30分で確定。
- 待機列のタイムアウト → 1分から5分に変更。
- 「今日の問い」のグループへの提示 → 不要（Non-Goals に追記）。
- 入室しないメンバーがいても満了まではグループを終了しない → 問題なし。

## なぜ行ったか

ユーザーから未解決事項への回答を得たため。
