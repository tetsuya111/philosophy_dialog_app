# ランダムコールのタスクリストを新規作成

## 何を行ったか

[.kiro/specs/random-call/tasks.md](../.kiro/specs/random-call/tasks.md) を新規作成した。design.md を13タスク（バックエンド設定・モデル・認証・サービス層・API・管理コマンド・テスト、フロントエンドのAPIクライアント・Home画面・通話画面、ドキュメント、手動確認）に分解し、各タスクに requirements のストーリー番号を対応付けた。M1（バックエンド）→ M2（フロントエンド接続）→ M3（ドキュメント・手動確認）の順で進める。

## なぜ行ったか

設計を実装可能な単位に分解し、進捗を追跡できるようにするため。
